How to play Robo Code

Each level is a small world of blocks with blue lamps on some of them. Build a program from tiles: forward, turn left, turn right, jump and light. Press Run and the robot follows the program one tile at a time, with the current tile highlighted. Light every lamp to clear the level. Later levels give you only a few slots, so you have to put repeated moves in functions F1 and F2, let a function call itself, repeat tiles with loops, and use pink and blue tiles that only run on matching floor colors.

Controls

  • Phone: tap a command tile to add it, tap a placed tile to remove it, or drag tiles into place. Tap Main, F1 or F2 to pick which program you are filling. Then tap Run or Step.
  • Keyboard/mouse: click or drag tiles. Arrow keys add forward and turns, J adds a jump, Space a light, 1 and 2 add function calls, Tab switches program, Backspace removes the last tile, Enter runs, S steps and Esc resets.

Tips

Look for patterns: if the robot does the same moves several times, put them in a function and call it. A function that ends by calling itself repeats until every lamp is lit. Forward never changes height, so use jump for steps. Fewer tiles earn more stars: three stars means you matched the shortest known program. Your progress and stars are saved in the browser.
